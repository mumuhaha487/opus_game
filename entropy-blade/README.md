# 熵刃 · ENTROPY BLADE

像素风 2D 横版动作肉鸽（Action Roguelite），东方奇幻题材。纯静态网页，无需安装、无需服务器、无需联网。

## 如何开始

在线游玩：<https://game.inc.re/entropy-blade/>（游戏汇总入口：<https://game.inc.re>）。

本地游玩：直接用浏览器（推荐 Chrome / Edge 最新版）打开 `index.html` 即可。

- 首次进入按任意键或点一下屏幕（会同时启用声音）。
- 建议全屏游玩：「游戏设置 → 全屏模式」，或按 F11。
- 存档（熵晶、天赋、设置、记录、上次选用的武器、劫难契约）自动保存在浏览器本地。

## 操作

| 动作 | 键盘 | 手柄 |
| --- | --- | --- |
| 移动 | A / D 或 ← / → | 左摇杆 / 十字键 |
| 跳跃 · 二段跳 · 蹬墙跳 | K / Space / Z | A |
| 攻击（连按出连段） | J / X | X |
| 蓄力攻击 | 长按 J（满蓄可到第二段） | 长按 X |
| **武技**：上段 / 下段 | ↑ + J / ↓ + J | ↑ / ↓ + X |
| 冲刺（无敌）· **突进武技** | L / Shift，冲刺中按 J | B / RB |
| 空中挑斩 / 空中下劈 | 空中 ↑ + J / 空中 ↓ + J | 同左 |
| **秘技**：静止 / 移动 / 空中 | I / ← → + I / 空中 I | Y |
| **秘技**：上 / 下（奥义） | ↑ + I / ↓ + I | ↑ / ↓ + Y |
| 秘技派生 | 施放中或刚结束时再按 I | 再按 Y |
| 互动 / 进门 / 拾取 | E / F | 十字键↑ / R3 |
| 穿过平台 | ↓ + 跳跃 | ↓ + A |
| 奖励重掷 | R | Y |
| 暂停（构筑 / 刻印 / 招式表） | Esc / P | Start |

（U、O、B、V 也可以当作 I 使用。）菜单支持方向键、Enter/J 确认、Esc 返回，也支持鼠标点击。

### 手机 / 平板

触屏设备会自动切换为触控操作（请横屏，竖屏时会提示旋转）：

- **左半屏**：浮动摇杆，手指按下的位置就是摇杆中心。推上 / 推下配合攻击键即为武技，推下配合跳跃即为穿过平台。
- **右下角图标按键**：攻击（随角色显示刀 / 枪 / 拳）、跳跃、冲刺（下方小点为剩余冲刺次数）、秘技（显示当前方向对应的秘技图标，外圈为灵力进度，奥义可用时会脉动）、互动（附近没有可互动物时变暗）。
- **右上角**：暂停。菜单直接点按即可，选角界面点武器栏切换武器。
- 按键会避开刘海与圆角（安全区域），支持震动反馈；点「全屏」后会尝试锁定横屏。

## 构筑系统

### 武器（出发前选择）
选角界面用 ↑↓ 选择武器，每名角色 3 把。武器改变角色的属性、外观与战斗特性，并显示在 HUD、暂停界面和结算界面上。

- **凛**：绯樱（打刀，暴击、终结技回灵）· 夜叉（大太刀，重击 + 终结技剑气）· 霜月（小太刀，快攻 + 见切回灵）
- **伊芙**：星辉（双枪，穿透、秘技减耗）· 龙息（霰弹枪，普通射击三连散射）· 寒星（长铳，高速弹、爆伤、减速）
- **罡**：镇岳（拳套，减伤、生命）· 雷鸣（臂铠，每 6 次命中引下落雷）· 赤焰（手甲，终结技与秘技附带燃烧）

### 武技（方向 + 攻击）
↑ + 攻击、↓ + 攻击、冲刺中攻击各有一个武技槽，每个槽有 2 门武技可选（每名角色共 6 门）。从「武学」奖励中习得，**重复参悟同一门武技来升级**，升级不只是加数值，还会解锁新的招式：

- **Lv1 起手**：武技本身（如凛的「飞燕」——飞身斜挑并放出剑气）
- **Lv2 派生**：起手后继续按攻击，派生出第二招（「燕回」空中回身二连斩）
- **Lv3 连段**：再按攻击接上连段（「燕舞」空中旋斩，卷住敌人）
- **Lv4 终式**：威力最强的终结技（「燕落·断空」俯冲落地，两侧放出剑气）

每升一级，该武技所有招式伤害 +12%。也可以「转修」为同槽位的另一门武技（保留等级）。

### 秘技（I + 方向，消耗灵力）
I 键根据当前状态释放 5 种不同的秘技，每种都有自己的效果、数值和**灵力（蓝条）消耗**：

| 输入 | 凛（默认 / 可转修） | 伊芙 | 罡 | 灵力 |
| --- | --- | --- | --- | --- |
| 地面静止 + I | 燕返架势 / 居合·断 | 魔弹狙击 / 浮游炮台 | 金刚身 / 气功波 | 20–35 |
| 移动中 + I | 影闪 / 千鸟 | 后跃速射 / 爆裂榴弹 | 震地冲锋 / 山崩投 | 15–25 |
| ↑ + I | 天降一闪 / 旋风刃 | 星落弹雨 / 追踪弹幕 | 升龙拳 / 地裂 | 25–30 |
| 空中 + I | 飞燕斩 / 樱吹雪 | 枪舞 / 束缚地雷 | 旋风腿 / 百裂拳 | 15–30 |
| **↓ + I（奥义）** | 月华千斩 / 八重樱·镇魂 | 湮灭光炮 / 天狼星陨 | 霸王崩拳 / 镇岳 | **70–75** |

- 秘技 **Lv2** 解锁派生：施放中或刚结束时再按 I，接出派生招式（如「影闪 → 影返」「狙击 → 追击狙」「升龙拳 → 龙坠」）。
- 秘技 **Lv3** 进化，获得额外效果。
- 灵力会自然恢复，命中敌人、极限闪避、部分刻印也会回复。↓ + I 的奥义消耗最多，威力也最大。

### 其他动作
- **连段**：4 段普攻，解锁「终式」后追加第 5 段。连打两下后停顿一拍再按攻击，进入另一套派生连段。
- **蓄力**：长按攻击蓄力，解锁「蓄力·极」后可蓄到第二段。
- **见切**：在敌人攻击即将命中的瞬间冲刺，触发子弹时间，此时按攻击发动必暴击的反击。
- **招式解锁**：终式、蓄力·极、云阶、见切·极、受身、壁走、灵脉。

## 游戏内容

- **3 名角色**，每人 60 余个招式：凛（刀，均衡近战）、伊芙（魔弹枪，远程爆发）、罡（拳法武僧，重装近战）。每名角色都有一张手绘立绘（`art/` 目录），以屏幕原生分辨率绘制在选角界面（斜切立绘卡轮播，选中角色居中发光，其余角色压暗待命，显示该角色的「最高评分」）、HUD 头像框（受击时闪烁抖动）和结算界面（失败时褪色，并显示本局评分 / 新纪录）上。
- **替换立绘**：把方形图片覆盖到 `art/rin.webp`、`art/eve.webp`、`art/gao.webp` 即可；删掉 `.webp` 后也可以直接放同名的 `.png` / `.jpg`。建议 1024×1024 左右，人物脸部大致在画面中上部。
- **4 个场景**，每个场景 5 层（3 层战斗 → 休憩 / 商店 → 首领）：

| 场景 | 地形 | 专属敌人 | 首领 |
| --- | --- | --- | --- |
| 第一大关 · 其一　落樱古道 | 平原、阶梯 | 提灯鬼、天狗、狐火（幻身）、竹林忍 | 荒鬼武将 ★★ 近战猛攻 · 鬼怒 |
| 第一大关 · 其二　苍雪寒山 | 冰面（会打滑）、阶梯、深谷 | 雪童子、冰蝠、霜僧（格挡）、雪狼（群狼） | 雪女·白霜 ★★★ 远程消耗 · 寒气 |
| 第一大关 · 其三　晶渊回廊 | 洞窟、高塔 | 晶蛛（碎晶）、棱镜（锁定光束）、浮游眼、盾卫、裂角兽 | 晶核女皇 ★★★ 召唤 · 弹幕 · 晶壁 |
| 终章　熵能核心 | 混合 | 虚咒师、熵影（裂影）、虚触 | 熵之王 ★★★★ 全能 · 三阶段 · 熵蚀 |

  - 前三个场景的房间布局类型各不相同；蚀虫、爆破虫、狙击者等通用敌人会在多个场景出现（狙击者在雪山改射冰箭）。
  - 首领特性：**鬼怒**——受击积攒怒气，满怒鬼化（霸体、加速、增伤），结束后力竭受伤 +50%；**寒气**——始终与你保持距离，冰系攻击叠加寒气，满 5 层冻结；**晶壁**——生命降至 66% / 33% 时召唤三座晶柱护体（减伤 90%），击碎全部晶柱使其失衡；**熵蚀**——终焉形态下虚空从两侧吞噬战场。
- **武学节奏**：开局参悟一门武学；第一大关的普通房间里一共只会再出现 1–2 次（每个场景至多 1 次，且不会每关都有）；每个首领必定额外掉落一次武学。商店偶尔会出售武学卷轴。
- **刻印**：7 个印系（疾风、连舞、残响、蓄势、猎杀、守御、灵器），同一印系集齐 3 种刻印触发共鸣。
- **路线选择**：门上方的图标就是通关后的奖励，包括刻印、武学、金币、生命、淬炼、熵晶、精英战、商店、休憩、混沌祭坛。
- **局外成长**：用熵晶购买 10 种永久天赋。熵晶在失败后也会保留。

### 劫难挑战（高难模式）

标题菜单选「劫难挑战」，选好角色与武器后进入「劫难契约」：自选劫数（debuff），每档劫数都有劫难值，劫难值累计到门槛就解锁对应的福缘（正面奖励），全部同时生效。

| 劫数 | 效果 | 劫难值 |
| --- | --- | --- |
| 凶煞 | 敌人生命 +25 / 50 / 80% | 2 / 4 / 6 |
| 锋芒 | 敌人伤害 +20 / 40 / 70% | 2 / 4 / 6 |
| 疾风骤雨 | 敌人行动速度 +15 / 30% | 3 / 6 |
| 箭雨 | 敌方弹幕速度 +25 / 50% | 2 / 4 |
| 精英横行 | 每个战斗房间额外 1 / 2 名精英（2 档时精英生命 +30%） | 2 / 5 |
| 增援 | 每个战斗房间多一波敌人 | 3 |
| 首领觉醒 | 首领生命 +30%、更早狂暴 / +60%、更快、开场即狂暴 | 3 / 6 |
| 枯木 | 治疗效果 -40 / 75% | 2 / 4 |
| 灵涸 | 灵力恢复 -40 / 70%，命中回灵 -25 / 50% | 2 / 4 |
| 断念 | 最大生命 -25%，天赋「复苏」失效 | 3 |
| 迷雾 | 看不到门后的奖励 | 2 |
| 贫者 | 商店价格 +40% | 1 |

| 劫难值 | 福缘 |
| --- | --- |
| 3 | 熵晶 +25% |
| 6 | 金币 +30% |
| 9 | 武学机缘：每个场景的武学上限 +1 |
| 12 | 开局额外铭刻一枚稀有刻印 |
| 16 | 重掷 +2，商店折扣 20% |
| 20 | 首领额外掉落一枚稀有刻印 |
| 25 | 开局额外参悟一次武学 |
| 30 | 伤害 +15%，击杀回复 1 点生命 |

劫难值越高，结算时熵晶倍率越高，最高劫难记录会保存下来。
- **画面与音频**：所有像素美术都是程序化生成的，带动态光照、辉光、视差背景和落樱粒子。所有音效和配乐都由 WebAudio 实时合成。

## 技术说明

- 只使用原生 JavaScript、Canvas 2D 和 WebAudio，没有任何依赖，也没有构建步骤。
- 角色由 2D 骨骼绑定 + 关键帧姿势描述，再经过自写的硬边像素光栅器烘焙成逐帧精灵（武器外观按所选武器重新烘焙）。
- 逻辑以固定 60Hz 步长运行。
