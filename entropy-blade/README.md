# 熵刃 · ENTROPY BLADE

像素风 2D 横版动作肉鸽（Action Roguelite），东方奇幻题材。纯静态网页，无需安装、无需服务器、无需联网。

## 如何开始

在线游玩：<https://game.inc.re/entropy-blade/>（游戏汇总入口：<https://game.inc.re>）。

本地游玩：直接用浏览器（推荐 Chrome / Edge 最新版）打开 `index.html` 即可。

- 首次进入按任意键或点一下屏幕（会同时启用声音）。
- 建议全屏游玩：「游戏设置 → 全屏模式」，或按 F11。
- 存档（熵晶、天赋、设置、记录、上次选用的武器、劫难契约）自动保存在浏览器本地。

### 手机 / 平板

触屏设备会自动切换为触控操作（请横屏，竖屏时会提示旋转）：

- **左半屏**：浮动摇杆，手指按下的位置就是摇杆中心。推上 / 推下配合攻击、技能、秘技键即为对应方向的招式，推下配合跳跃即为穿过平台。
- **右下角图标按键**（右手拇指从右往左滚动）：最右下是**攻击**（随角色显示刀 / 枪 / 拳）；攻击正上方是**跳跃**；攻击斜上方是**技能（U）**；攻击左边是**冲刺**（下方小点为剩余冲刺次数）；冲刺左边是**秘技（I）**；秘技上方是**互动**（附近没有可互动物时变暗）。
- **技能键**显示摇杆当前方向对应的技能图标和方向角标，外圈是冷却进度，冷却中会变暗；可以接第二 / 第三段时按键会闪动。**秘技键**同理，外圈为灵力进度，奥义可用时会脉动。
- **右上角**：暂停。菜单直接点按即可，选角界面点武器栏切换武器。
- 按键会避开刘海与圆角（安全区域），支持震动反馈；点「全屏」后会尝试锁定横屏。

## 构筑系统

### 武器（出发前选择）
选角界面用 ↑↓ 选择武器，每名角色 3 把。武器改变角色的属性、外观与战斗特性，并显示在 HUD、暂停界面和结算界面上。

- **凛**：绯樱（打刀，暴击、终结技回灵）· 夜叉（大太刀，重击 + 终结技剑气）· 霜月（小太刀，快攻 + 见切回灵）
- **伊芙**：星辉（双枪，穿透、秘技减耗）· 龙息（霰弹枪，普通射击三连散射）· 寒星（长铳，高速弹、爆伤、减速）
- **罡**：镇岳（拳套，减伤、生命）· 雷鸣（臂铠，每 6 次命中引下落雷）· 赤焰（手甲，终结技与秘技附带燃烧）

### 武学：武技 · 技能 · 秘技（一个奖励池，每门各有进阶路线）
「武学」奖励窗口里，武技、技能、秘技（以及招式解锁）都出现在同一组卡牌中。重复参悟同一门武学会进阶，但**每门武学的等级上限和每一级的效果都各不相同**：

- **等级上限因武学而异**：有的只有 1 级（习得即大成，例如凛的「追风」一次给出整套连段、罡的「铁桥」自带霸体），有的 2 级，有的 3 级；到达上限后不会再出现在奖励里。
- **每一级给什么因武学而异**：有的先解锁派生、有的先进化；有的一级解锁一招，有的一级解锁两招；技能有的一次开启第二、三段，有的开局就有全部三段。
- **独有效果**：部分武学在某一级获得只属于它的效果，共 33 种，全游戏不重复——比如凛「千鸟」的「饮血」（命中吸血）、伊芙「魔弹」的「跳弹」、罡「百裂拳」的「连环气爆」。
- **三名角色风格不同**：凛的独有效果偏向斩杀、吸血、标记与空中连击；伊芙偏向弹道（追踪、跳弹、电弧、减速、冷却回填）；罡偏向护体、余震、爆炸与增益。三人的等级上限分布也各不相同。
- 已经拥有的武学更容易再次出现；卡牌上会写明这一级具体给什么、之后还剩哪几级。

### 武技（方向 + 攻击）
↑ + 攻击、↓ + 攻击、冲刺中攻击各有一个武技槽，每个槽有 2 门武技可选（每名角色共 6 门）。每门武技都是 4 招连段（起手 → 派生 → 连段 → 终式），前一招后继续按攻击接出；每一级解锁到哪一招由这门武技自己决定（见下方一览）。也可以「转修」为同槽位的另一门武技（等级保留，但不超过新武技的上限）。

### 技能（U + 方向，不耗灵力）
U 键是不消耗灵力的技能键，四个方向各一招、各自冷却；技能命中也会回复灵力，正好给秘技充能。开局四招都已习得，靠武学进阶开启后续段数（施放中或刚结束时再按 U）：

| 输入 | 凛 | 伊芙 | 罡 |
| --- | --- | --- | --- |
| U（远程） | 飞刃 → 交叉刃 → 千刃（1.1 秒） | 魔弹 → 三连魔弹 → 星爆弹（1.0 秒） | 气弹 → 双掌气弹 → 气功炮（1.2 秒） |
| ↑ + U | 升月斩 → 月轮 → 坠月（3.0 秒） | 照明星 → 双星 → 流星雨（3.0 秒） | 气旋 → 双气旋 → 炎龙（3.0 秒） |
| ↓ + U | 地走刃 → 刃林 → 断地（3.4 秒） | 弹跳雷 → 连锁雷 → 雷阵（3.2 秒） | 震地波 → 岩刺 → 地震（3.4 秒） |
| 冲刺中 U | 影刃 → 回刃 → 影杀（4.0 秒） | 回旋射击 → 交叉火力 → 幻影齐射（2.4 秒） | 虎掌 → 双虎掌 → 虎啸（2.4 秒） |

括号内为冷却时间。

### 秘技（I + 方向，消耗灵力）
I 键根据当前状态释放 5 种不同的秘技，每种都有自己的效果、数值和**灵力（蓝条）消耗**：

| 输入 | 凛（默认 / 可转修） | 伊芙 | 罡 | 灵力 |
| --- | --- | --- | --- | --- |
| 地面静止 + I | 燕返架势 / 居合·断 | 魔弹狙击 / 浮游炮台 | 金刚身 / 气功波 | 20–35 |
| 移动中 + I | 影闪 / 千鸟 | 后跃速射 / 爆裂榴弹 | 震地冲锋 / 山崩投 | 15–25 |
| ↑ + I | 天降一闪 / 旋风刃 | 星落弹雨 / 追踪弹幕 | 升龙拳 / 地裂 | 25–30 |
| 空中 + I | 飞燕斩 / 樱吹雪 | 枪舞 / 束缚地雷 | 旋风腿 / 百裂拳 | 15–30 |
| **↓ + I（奥义）** | 月华千斩 / 八重樱·镇魂 | 湮灭光炮 / 天狼星陨 | 霸王崩拳 / 镇岳 | **70–75** |

- 派生：解锁后，施放中或刚结束时再按 I，接出派生招式（如「影闪 → 影返」「狙击 → 追击狙」「升龙拳 → 龙坠」）。有的秘技自带派生，有的要升级才解锁，有的没有派生。
- 灵力会自然恢复，命中敌人、极限闪避、部分刻印也会回复。↓ + I 的奥义消耗最多，威力也最大。

### 其他动作
- **连段**：4 段普攻，解锁「终式」后追加第 5 段。连打两下后停顿一拍再按攻击，进入另一套派生连段。
- **蓄力**：长按攻击蓄力，解锁「蓄力·极」后可蓄到第二段。
- **见切**：在敌人攻击即将命中的瞬间冲刺，触发子弹时间，此时按攻击发动必暴击的反击。
- **招式解锁**：终式、蓄力·极、云阶、见切·极、受身、壁走、灵脉。

## 游戏内容

- **3 名角色**，每人 70 余个招式：凛（刀，均衡近战）、伊芙（魔弹枪，远程爆发）、罡（拳法武僧，重装近战）。每名角色都有一张手绘立绘（`art/` 目录），以屏幕原生分辨率绘制在选角界面（斜切立绘卡轮播，选中角色居中发光，其余角色压暗待命，显示该角色的「最高评分」）、HUD 头像框（受击时闪烁抖动）和结算界面（失败时褪色，并显示本局评分 / 新纪录）上。
- **替换立绘**：把方形图片覆盖到 `art/rin.webp`、`art/eve.webp`、`art/gao.webp` 即可；删掉 `.webp` 后也可以直接放同名的 `.png` / `.jpg`。建议 1024×1024 左右，人物脸部大致在画面中上部。
- **开始游戏**：选好角色与武器后选择**普通模式 / 困难模式**（两者带不同强度的辅助：通关回复、生命上限、减伤、入场护盾、见切窗口、补给治疗、蓄力加速、击杀回复）；「劫难挑战」不带这些辅助。
- **4 个场景**，每个场景 7 层（5 层房间 → 休憩 / 商店 → 首领）：

| 场景 | 地形 | 专属敌人 | 首领 |
| --- | --- | --- | --- |
| 第一大关 · 其一　落樱古道 | 平原、阶梯 | 提灯鬼、天狗、狐火（幻身）、竹林忍 | 荒鬼武将 ★★ 近战猛攻 · 鬼怒 |
| 第一大关 · 其二　苍雪寒山 | 冰面（会打滑）、阶梯、深谷 | 雪童子、冰蝠、霜僧（格挡）、雪狼（群狼） | 雪女·白霜 ★★★ 远程消耗 · 寒气 |
| 第一大关 · 其三　晶渊回廊 | 洞窟、高塔 | 晶蛛（碎晶）、棱镜（锁定光束）、浮游眼、盾卫、裂角兽 | 晶核女皇 ★★★ 召唤 · 弹幕 · 晶壁 |
| 终章　熵能核心 | 混合 | 虚咒师、熵影（裂影）、虚触 | 熵之王 ★★★★ 全能 · 三阶段 · 熵蚀 |

  - 前三个场景的房间布局类型各不相同；蚀虫、爆破虫、狙击者等通用敌人会在多个场景出现（狙击者在雪山改射冰箭）。
  - 首领特性：**鬼怒**——受击积攒怒气，满怒鬼化（霸体、加速、增伤），结束后力竭受伤 +50%；**寒气**——始终与你保持距离，冰系攻击叠加寒气，满 5 层冻结；**晶壁**——生命降至 66% / 33% 时召唤三座晶柱护体（减伤 90%），击碎全部晶柱使其失衡；**熵蚀**——终焉形态下虚空从两侧吞噬战场。
- **武学节奏**：开局参悟一门武学；**每个场景在首领之前固定出现 2 次武学**（一次在前两层，一次在第 4–5 层，无论走哪扇门都会有，作为该房间的额外奖励），**首领再掉落 1 次**。商店偶尔会出售武学卷轴，混沌祭坛也可以以血换技。
- **刻印**：7 个印系（疾风、连舞、残响、蓄势、猎杀、守御、灵器），同一印系集齐 3 种刻印触发共鸣。
- **路线选择**：门上方的图标就是通关后的奖励，包括刻印、金币、生命、淬炼、熵晶、精英战、商店、休憩、混沌祭坛；通往「武学层」的门会额外显示卷轴角标（「+ 武学」）。
- **局外成长**：用熵晶购买 10 种永久天赋。熵晶在失败后也会保留。

## 技术说明

- 只使用原生 JavaScript、Canvas 2D 和 WebAudio，没有任何依赖，也没有构建步骤。
- 角色由 2D 骨骼绑定 + 关键帧姿势描述，再经过自写的硬边像素光栅器烘焙成逐帧精灵（武器外观按所选武器重新烘焙）。
- 逻辑以固定 60Hz 步长运行。
